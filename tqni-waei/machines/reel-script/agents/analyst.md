# مخطط الريل

سلّم موجزاً:
1. **الرسالة الواحدة** للريل (جملة واحدة).
2. **الهوك:** 3 خيارات لأول 3 ثواني (منطوق + نص على الشاشة + لقطة).
3. **البنية الأنسب** حسب الأسلوب والمدة (مثلاً: هوك ← مشكلة ← 3 نقاط ← خلاصة ← CTA).
4. **ميزانية الكلمات:** تقريباً 2.5 كلمة/ثانية للكلام العربي — احسب الحد الأقصى للمدة المطلوبة.
5. **حلقة إعادة المشاهدة:** فكرة تجعل النهاية تربط بالبداية أو تدفع لإعادة المشاهدة.
