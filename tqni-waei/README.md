# منصة «تقني واعي» — متجر مكائن الذكاء الاصطناعي

موقع يبيع **مكائن** ذكاء اصطناعي، وبعدها الدورات. كل ماكينة فيها **فريق خبراء (وكلاء Claude)** يشتغل على طلب العميل مرحلة بمرحلة:

```
تحليل الطلب → الإنتاج → لجنة مراجعة (4 خبراء بالتوازي) → التحسين → التدقيق النهائي والتسليم
```

- **الدفع يدوي:**
  - العميل يدفع بكليك أو المحافظ، أو حوالة بنكية، أو PayPal.
  - بعد التحويل يرفع صورة الإيصال.
  - **أنت تؤكد** الدفع من لوحة التحكم، وعندها تنفتح الماكينة في حسابه.
- **التجربة المجانية:** تجربة واحدة لكل ماكينة لكل مستخدم.
- **العروض:** ماكينة واحدة 20$، أي 3 مكائن 50$، كل المكائن 99$.

## التشغيل لأول مرة

1. **Supabase** (مجاني): أنشئ مشروعاً على supabase.com، ثم:
   - من SQL Editor: الصق محتوى `supabase/schema.sql` واضغط Run.
   - من Authentication → URL Configuration: ضع رابط موقعك في Site URL، وأضف `https://موقعك/auth/callback` في Redirect URLs.
2. **Claude API**: خذ مفتاحاً من console.anthropic.com.
3. انسخ `.env.example` إلى `.env.local` وعبّئ القيم، وضع إيميلك في `ADMIN_EMAILS`.
4. للتشغيل محلياً: `npm install && npm run dev`
5. للنشر: ارفع المجلد على **Vercel** واجعل Root Directory = `tqni-waei`، وأضف نفس متغيرات البيئة.

## أين أعدّل؟

| ماذا | أين |
|------|-----|
| الاسم، العروض، **بيانات الدفع**، آراء العملاء، الدورات | `src/content/site.ts` |
| الألوان | أول `src/app/globals.css` |
| المكائن (الاسم، السعر، الحقول، الفريق، قريباً/متاحة) | `machines/<slug>/plugin.json` |
| مهارات الوكلاء | `machines/<slug>/agents/*.md` و `machines/_shared/agents/*.md` |

## إضافة أو تحديث مهارة

**الطريقة 1: من لوحة التحكم (يطبّق فوراً)**
1. افتح `/admin` وانزل إلى «مهارات فرق المكائن».
2. اختر الماكينة والوكيل.
3. ارفع ملف `.md` واضغط حفظ.

**الطريقة 2: عن طريق Claude Code**
أعطِ Claude ملف السكيل واطلب منه مثلاً «حدّث مهارة الوكيل X في ماكينة Y» أو «أضف ماكينة جديدة من هذا السكيل». تعليماته موجودة في `CLAUDE.md`.

## هيكل الماكينة

```
machines/prompt-engineer/
├── plugin.json          # البيانات + تركيبة الفريق
└── agents/
    ├── analyst.md       # محلل الطلب
    ├── creator.md       # المنتج الرئيسي
    └── reviewer-llm.md  # مراجع متخصص
# + وكلاء مشتركون: reviewer-expert, reviewer-audience, reviewer-redteam, refiner, qa-final
```

عدد الوكلاء في أي مرحلة قابل للزيادة: أضف أسماءهم في `agents` داخل المرحلة ليشتغلوا بالتوازي. لكن كل وكيل إضافي يعني استدعاء Claude إضافياً، أي تكلفة ووقتاً أكثر.
