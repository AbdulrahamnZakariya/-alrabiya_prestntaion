# منصة «تقني واعي» — متجر مكائن الذكاء الاصطناعي

موقع يبيع **مكائن** ذكاء اصطناعي (وبعدها الدورات). كل ماكينة فيها **فريق خبراء من وكلاء Claude**.

## نوعان من المكائن

| النوع | المكائن | أين تشتغل | ماذا تسلّم |
|---|---|---|---|
| **نصية** (`runner: text`) | البرومتات (RCTFS)، الكاروسيل، الهوكات والكابشن، سكربت الريلز | داخل الموقع: فريق من 8 وكلاء على 5 مراحل | نص منسق، أو سلايدات مصممة PNG (الكاروسيل) |
| **سيرفر** (`runner: worker`) | البرزنتيشن، استنساخ البرزنتيشن، دراسات الجدوى، الوورد والإكسل، المونتاج | سيرفر المعالجة (`../worker`): Claude Agent SDK + بلجن «تقني باني» أو سكل المونتاج | ملفات: PPTX، DOCX، XLSX، PDF، MP4 |

فريق المكائن النصية:
```
تحليل الطلب ← الإنتاج ← لجنة مراجعة (4 خبراء بالتوازي) ← التحسين ← التدقيق النهائي والتسليم
```

طلبات مكائن السيرفر:
```
العميل يعبّي النموذج ويرفع ملفاته مباشرة للمخزن ← الطلب يدخل الطابور
← سيرفر المعالجة يسحبه ويشغّل الفريق ← يرفع الملفات ← العميل ينزّلها من «حسابي»
```

## البيع
- الدفع يدوي: كليك/محافظ، حوالة بنكية، PayPal. العميل يرفع الإيصال، **وأنت تؤكد** من `/admin`، وعندها تنفتح الماكينة.
- **تجربة مجانية واحدة** لكل ماكينة لكل مستخدم (التشغيل الفاشل ما ينحسب).
- **كل شراء يشمل رصيداً**: 40 استخدام للمكائن النصية، و3 طلبات لمكائن السيرفر (قابلة للتعديل بـ `usesPerPurchase` في plugin.json). الشراء مرة ثانية يجدّد الرصيد.
- العروض: ماكينة 20$، أي 3 مكائن 50$، كل المكائن 99$.

## التشغيل والنشر
الدليل الكامل خطوة بخطوة (Supabase، الدومين، السيرفر): **[`docs/DEPLOY.md`](../docs/DEPLOY.md)**.

للتطوير محلياً:
```bash
cp .env.example .env.local   # عبّئ القيم
npm install && npm run dev
```

## أين أعدّل؟

| ماذا | أين |
|------|-----|
| الاسم، العروض، **بيانات الدفع**، آراء العملاء، الدورات | `src/content/site.ts` |
| الألوان والخط | أول `src/app/globals.css` و`src/app/fonts.ts` |
| المكائن (الاسم، السعر، الحقول، الفريق، الرصيد، قريباً/متاحة) | `machines/<slug>/plugin.json` |
| مهارات وكلاء المكائن النصية | `machines/<slug>/agents/*.md` و`machines/_shared/agents/*.md` |
| مهمة فريق ماكينة السيرفر | `machines/<slug>/worker.md` |
| الرصيد المشمول بالشراء والتجربة المجانية | `src/lib/access.ts` |

## إضافة أو تحديث مهارة

**من لوحة التحكم (فوري، للمكائن النصية):** `/admin` ← «مهارات فرق المكائن» ← اختر الماكينة والوكيل ← ارفع `.md` ← حفظ.

**عن طريق Claude Code:** أعطه السكيل أو البلجن واطلب منه التحديث. تعليماته في `CLAUDE.md`.

## هيكل ماكينة نصية

```
machines/prompt-engineer/
├── plugin.json          # البيانات + تركيبة الفريق
└── agents/
    ├── analyst.md       # محلل الطلب
    ├── creator.md       # المنتج الرئيسي
    └── reviewer-llm.md  # مراجع متخصص
# + وكلاء مشتركون: reviewer-expert, reviewer-audience, reviewer-redteam, refiner, qa-final
```

- **ماكينة الكاروسيل** مخرجها ليس نصاً: آخر وكيل يسلّم السلايدات كبيانات (حسب `output.schema.json`)، والموقع يرسمها بألوان العميل وخطه، وينزّلها صور PNG بمقاس 1080×1440. ومحللها يبحث في الإنترنت ليتحقق من الأرقام والأخبار (`"webSearch": true` في المرحلة).
- عدد الوكلاء في أي مرحلة قابل للزيادة: أضف أسماءهم في `agents` داخل المرحلة ليشتغلوا بالتوازي. لكن كل وكيل إضافي يعني استدعاء Claude إضافياً، أي تكلفة ووقتاً أكثر.
