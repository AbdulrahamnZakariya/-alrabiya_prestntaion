# نتائج البحث — منصة «تقني واعي» (2026-09-28)

> ملاحظة: البنود المعلّمة بـ [غير مؤكد] تحتاج تحقق قبل الاعتماد عليها.

## 1) الخلاصة

- **الفكرة غير موجودة عربياً بهذا الشكل.** بيع "مكائن" ذكاء اصطناعي منفصلة تُفتح يدوياً بعد الدفع، مع دفع أردني محلي (CliQ)، فراغ حقيقي في السوق.
- **فرصة مميزة:** أدوات الكابشن العالمية (مثل Submagic) تعرض الكابشن العربي بشكل غلط. ماكينة ريلز بكابشن عربي صحيح هي ميزة تنافسية.
- **لا يوجد مولّد دراسات جدوى ناضج مفتوح المصدر.** هذه فرصة ثانية.

## 2) الدفع في الأردن

| الطريقة | الوضع | التوصية |
|---|---|---|
| **CliQ** | فوري 24/7، يعمل من كل البنوك والمحافظ، الدفع على Alias (مثل TAQNIWAEI) ويظهر الاسم الحقيقي للمستلم | **الطريقة الأساسية.** Alias واحد يغطي كل البنوك والمحافظ |
| المحافظ (Zain Cash, Orange Money, UWallet, Dinarak…) | كلها مربوطة بـ CliQ | لا داعي لشرح كل محفظة لحال |
| حوالة بنكية دولية (IBAN) | للعملاء من خارج الأردن | متاحة |
| PayPal | الحسابات الأردنية العادية إرسال فقط غالباً. الاستقبال عبر خدمة **بنك القاهرة عمان** | يحتاج حساب CAB [غير مؤكد: الشروط الحالية] |
| مستقبلاً | Tap Payments (روابط دفع للمؤثرين)، PayTabs، HyperPay، Zbooni، Gumroad (يدعم الأردن)، Paddle | Stripe غير متاح في الأردن |

ملاحظة: حسب رؤيا نيوز، تحويلات CliQ لحسابات التجار والشركات عليها رسوم ثابتة لكل حركة. الحسابات الشخصية بدون رسوم [غير مؤكد: التفاصيل].

- أدوات شهرية: $6–29
- منتجات رقمية لمرة واحدة: $9–27
- سعرك (20$ لماكينة واحدة، 50$ لثلاث) **في منتصف السوق ومنطقي**.
- اقتراحات:
  - باقة "كل المكائن" بـ $79–99
  - أسعار بالدينار (14 / 35 JD)
  - منتج دخول رخيص بـ $5–10
  - تحديد صلاحية الوصول (مدى الحياة أو حد استخدام)، لأن تكلفة الـ API مستمرة

## 5) مكائن مقترحة إضافية

1. كاتب هوكات وكابشن باللهجات (أردني، خليجي، مصري)
2. مولّد سكربت ريلز (هوك، محتوى، CTA). يكمّل ماكينة المونتاج
3. صانع ثمبنيل وكفر بخط عربي صحيح
4. تقويم محتوى 30 يوم
5. مترجم ترجمات SRT عربي ↔ إنجليزي
6. تعليق صوتي عربي AI
7. كاتب إعلانات Meta / TikTok / Snap
8. صانع CV متوافق مع ATS (عربي وإنجليزي)
9. مولّد هوية تجارية (اسم، ألوان، نبرة)
10. صانع صفحة هبوط / Link-in-bio
11. سكربتات ردود وبيع واتساب
12. كاتب وصف منتجات للمتاجر
13. خطة عمل + Pitch Deck
14. منسّق أبحاث وتقارير جامعية

## 7) مسار الدفع والتفعيل المقترح

```
اختيار ماكينة/باقة → اختيار طريقة الدفع (CliQ / IBAN / PayPal)
→ رفع صورة الإيصال + رقم الحركة (تخزين خاص)
→ طلب بحالة "بانتظار التأكيد"
→ لوحة المالك: [تأكيد] أو [رفض + السبب]
→ عند التأكيد: تُفتح الماكينة في حساب المستخدم + إشعار (إيميل/واتساب)
```
