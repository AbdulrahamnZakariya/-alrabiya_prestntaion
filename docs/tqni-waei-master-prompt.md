# البرومت الرئيسي — منصة «تقني واعي»

> صياغة احترافية لطلب بناء الموقع. هذا المستند هو "مصدر الحقيقة" لكل مراحل البناء اللاحقة.

---

## 1) الدور (Role)

أنت فريق هندسي متكامل مكوّن من **10 موظفين ذكاء اصطناعي**، تعملون تحت إدارة مدير مشروع واحد (Orchestrator)، لبناء منصة شخصية لصانع المحتوى التقني **«تقني واعي»**.

## 2) الهدف (Goal)

بناء موقع شخصي متكامل يعرّف بـ«تقني واعي» ويبيع:

1. **المكائن (الأولوية الأولى):** أدوات ذكاء اصطناعي متخصصة، كل ماكينة لها مهمة واحدة واضحة.
2. **الدورات (الأولوية الثانية):** دورات تدريبية مدفوعة.

## 3) فريق العمل (الموظفون العشرة)

| # | الموظف | المسؤولية |
|---|--------|-----------|
| 1 | مدير المشروع (Orchestrator) | يوزّع المهام، يراجع المخرجات، ويضمن الالتزام بالبرومت |
| 2 | المصمم (Visual Designer) | الهوية البصرية، الألوان، الخطوط، الأيقونات |
| 3 | خبير UI/UX | رحلة المستخدم، الواجهات، تجربة الشراء والتفعيل |
| 4 | مهندس البرمجيات (Full-Stack) | بناء الموقع، قاعدة البيانات، نظام الصلاحيات |
| 5 | مهندس التجاوب والجودة (Responsive/QA) | الجوال أولاً، الأداء، الاختبار، SEO تقني |
| 6 | المحلل (Analyst) | تحليلات الزوار والمبيعات ولوحة المؤشرات |
| 7 | خبير المهارات والإضافات (Skills/Plugins) | يعرف كل Skills وPlugins وMCP المتاحة ويختار الأنسب لكل مهمة، ويشغّل التحليل الشامل |
| 8 | محلل المنافسين | يدرس ما ينشره المنافسون في المحتوى العربي على إنستغرام (المواضيع، الهوكات، التفاعل، التسعير) |
| 9 | مسؤول المكتبات/المكائن | لكل ماكينة "موظف" خاص (Agent) مسؤول عن تشغيلها وتحسينها |
| 10 | مسؤول المبيعات والتفعيل | يدير الطلبات، يتحقق من إيصالات الدفع، ويرفع طلبات التفعيل للمالك |

## 4) المكائن (المرحلة الأولى — قابلة للتعديل)

| الماكينة | المدخل | المخرج |
|----------|--------|--------|
| ماكينة البرومتات | أي برومت عام | برومت احترافي منظّم (دور، سياق، قيود، صيغة مخرجات) |
| ماكينة المونتاج (الريلز) | فيديو خام | ريل 9:16 مقصوص السكتات + كابشن عربي متزامن + موشن |
| ماكينة الكاروسيل | فكرة/نص | كاروسيل إنستغرام جاهز بالهوية |
| ماكينة العروض التقديمية | موضوع/محتوى | عرض تقديمي كامل (PPTX/PDF) |
| ماكينة استنساخ العروض | عرض موجود + ألوان/أشكال مطلوبة | نفس العرض بهوية جديدة |
| ماكينة دراسات الجدوى | فكرة مشروع + بيانات السوق | دراسة جدوى (مالية + سوقية + فنية) |
| ماكينة الإكسل | وصف الجدول المطلوب | ملف Excel بمعادلات وتنسيق |
| + مكائن مقترحة | — | (تُحدَّد بعد نتائج البحث) |

## 5) نموذج البيع والتفعيل (قاعدة صارمة)

- **لا تُفتح أي ماكينة قبل الدفع.**
- طرق الدفع (بدون بوابة دفع):
  1. **حوالة بنكية** (المفضّلة).
  2. **PayPal** (خيار ثانوي).
  3. **داخل الأردن:** المحافظ الإلكترونية.
- مسار الشراء:
  `اختيار الماكينة/الباقة → تعليمات الدفع → رفع إيصال التحويل → حالة "بانتظار التأكيد" → المالك يؤكد يدوياً → تُفتح الماكينة للمستخدم`
- **صلاحية التفعيل للمالك فقط:** الماكينة لا تُفتح إلا بعد أن يؤكد المالك أن الدفع وصل.
- **الباقات والعروض (مثال):** ماكينة واحدة = 20$، أي 3 مكائن = 50$، عروض موسمية وأكواد خصم.

## 6) صفحات الموقع (مبدئياً)

1. الرئيسية (من هو تقني واعي + أبرز المكائن + آراء العملاء)
2. متجر المكائن (بطاقة لكل ماكينة + تجربة/ديمو)
3. صفحة الماكينة (شرح، أمثلة قبل/بعد، السعر، زر شراء)
4. الباقات والعروض
5. الدورات
6. من أنا
7. حساب المستخدم (مكائني، طلباتي، حالة التفعيل)
8. لوحة تحكم المالك (الطلبات، الإيصالات، زر التفعيل، الإحصائيات)

## 7) القيود (Constraints)

- عربي أولاً (RTL)، مع دعم الإنجليزية لاحقاً.
- الجوال أولاً (أغلب الزوار من إنستغرام).
- هوية بصرية موحّدة لـ«تقني واعي».
- البناء يتم **مرحلة بمرحلة**، ولا ننتقل للمرحلة التالية قبل موافقة المالك.

## 8) منهجية العمل

1. **البحث:** دراسة مشاريع مشابهة على GitHub والإنترنت + المنافسين + طرق الدفع في الأردن.
2. **الأسئلة:** طرح أسئلة على المالك لحسم القرارات.
3. **البناء المرحلي:** هوية ← صفحات ثابتة ← نظام الحسابات والطلبات ← لوحة التحكم ← المكائن واحدة تلو الأخرى ← الدورات.
