# البلجنز (على السيرفر فقط)

هذا المجلد يحتوي بلجنز المكائن الثقيلة. **لا يُرفع للريبو** لأنها منتجات خاصة (الريبو عام).

| المجلد | يُستخدم في | المصدر |
|---|---|---|
| `taqni-bani/` | البرزنتيشن، الاستنساخ، دراسات الجدوى، الوورد والإكسل | `taqni-bani.plugin` |
| `video-ad-editor/` | ماكينة المونتاج | سكل `video-ad-editor` |

للتركيب:
```bash
bash worker/scripts/add-plugin.sh ~/taqni-bani.plugin
bash worker/scripts/add-plugin.sh ~/video-ad-editor.zip
```
